Corrected figure used here: **208 units / $2,075.84**.
4. **Flag 4 — Food total off by $8.00.** Reported $7,697.50; line items sum to **$7,705.50**.
5. **Flag 5 — Reebok pair count unknown.** "2 boxes" valued at $3,300 — count pairs at staging (back, upstairs) so premium distribution can be planned.
6. **Reported vs. recomputed:** the source "reported grand total" of $20,855.28 covered only the retail/household section and carries the errors above. The full recomputed in-kind total for this event is **~$69,010.86**.
